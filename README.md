# LuxeStrands Landing Page

Premium hair care landing page built with vanilla HTML, CSS, and JavaScript.

## Features
- Fully responsive (mobile-first at 375px+)
- Sticky navigation with smooth scrolling
- Hero with strong CTA above the fold
- Benefits, How It Works, Testimonials, FAQ, and lead capture form
- Second CTA with working email capture form
- Production-ready static site
